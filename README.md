# The Block Graph — public support

[Open The Block Graph](https://blockgraph.projects.astroatomica.net/) · [Report a bug or request a feature](https://github.com/Astro-Atomica/Minecraft-Block-Graph-Public) · [Search existing reports](https://github.com/Astro-Atomica/Minecraft-Block-Graph-Public/issues)

The Block Graph is an Astro Atomica website for exploring how Minecraft resources connect, comparing Java and Bedrock acquisition routes, and planning builds. This repository is its public support tracker and reporting guide. Website source code and internal development work are maintained separately.

## What to report

No login is needed to read this repository or browse issues and feature requests. To submit a report without logging in, use [Contact Astro Atomica](https://www.astroatomica.com/contact), mention **The Block Graph**, and include the affected URL and details below. Contact reports are sent privately; they do not automatically create a GitHub issue.

The GitHub forms below are an optional route for people with a GitHub account. GitHub requires sign-in to create issues, comment, or subscribe to updates.

| Report | Use it for |
| --- | --- |
| [Website bug](https://github.com/Astro-Atomica/Minecraft-Block-Graph-Public/issues/new?template=bug-report.yml) | Broken pages, controls, diagrams, saved plans, layout, accessibility, or unexpected solver results |
| [Minecraft data correction](https://github.com/Astro-Atomica/Minecraft-Block-Graph-Public/issues/new?template=data-correction.yml) | Incorrect or missing recipes, trades, drops, acquisition paths, farm requirements, or edition-specific behavior |
| [Feature request](https://github.com/Astro-Atomica/Minecraft-Block-Graph-Public/issues/new?template=feature-request.yml) | A new capability or an improvement that would help you use the website |

Unsure which fits? Pick the closest form and describe what happened. You do not need to understand the code or know the solution.

## Before opening a report

1. Search existing reports, including closed issues. Add useful details to an existing report when it matches yours.
2. Copy the address of the affected page and note whether you selected Java or Bedrock.
3. For a website bug, note the build number in the footer, your browser, and your device.
4. Describe what you expected, what happened, and the steps someone else can follow.

See [Reporting guide](docs/reporting-issues.md) for examples, screenshots, plan exports, and Minecraft evidence. Missing optional details should not stop you from reporting a problem.

## Coverage and game versions

The website is in alpha. Java and Bedrock use separate versioned datasets, and illustrated farms can have conditions or validation gaps. Check [Coverage & known gaps](https://blockgraph.projects.astroatomica.net/coverage/) and the conditions and evidence on the affected page. A listed route or drawn blueprint does not establish that a farm was tested in-game. Reports of missing or incorrect behavior are welcome.

Please distinguish the Minecraft version shown by the website from the version you actually played. They may differ.

## Contact and updates

GitHub reports and attachments are public. For private details, or if you do not have a GitHub account, use [Contact Astro Atomica](https://www.astroatomica.com/contact). Mention **The Block Graph** and include the same reproduction details.

Follow the issue's comments for questions and resolution updates. A closed report may be a duplicate, an explanation, or a released fix; read the closing comment for the outcome and any fixing build number. See [Support process](docs/support-process.md).

The Block Graph is an unofficial project, not affiliated with Mojang or Microsoft. This tracker covers the website, not Minecraft account, purchase, server, or installation support.
